# asm

The purpose of this repository is to learn assembly, by solving common Computer Sceince problems

The assembler used here is [flat assembler](https://flatassembler.net/)

Contents
========
```
[x] Hello, World
[ ] Factorials `n! = (n)*(n-1)*(n-2)*(n-3)*...*(1)`
[x] Fibonacci Sequence `n[i] = n[i-1]+n[i-2], n[0]=0, n[1]=1`
```


```shell
$ ./build.py 
===============================
>> running program : [Hello-World]
Hello, World !
>> running program : [Fibonacci]
Fibonacci(32) = 2178309
```
